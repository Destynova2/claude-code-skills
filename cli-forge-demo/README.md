# cli-forge-demo

**Author:** [Destynova2](https://github.com/Destynova2)

Drop-in Claude Code skill that forges a **reproducible live-demo kit** for any project — the same demo, flawlessly, every time.

- Theatre model: script + blocking, same show every night, reset the stage, the understudy
- 7 evidence-backed laws (Great Demo!, Gong 76-second rule, live-coding survival, keynote "show don't tell")
- 2-axis tiers: intent (technique / fonctionnel / commercial / pédagogique) × support (live / gif / cast / video / interactive)
- Dynamic support recommendation, forceable with `--support`
- Runner-native automation — make / just / task / npm / ansible / flux / chainsaw (never an imposed `.sh`)
- Deterministic seed + idempotent reset, pre-flight checklist, backup recording
- VHS `.tape` GIFs (CI-able, doubles as integration test), asciinema cast/SVG, self-guided walkthroughs
- 12 named anti-patterns (Demo Gods, Feature Tour, Cold Open, Mystery Data, Silent Movie…)
